# Contract: CLI Schema

**Tool**: `zensical-pdf`
**Entry point**: `zensical-pdf` (installed via `pip install`)

---

## Global options

These options are accepted by all subcommands.

| Option | Short | Type | Default | Description |
|--------|-------|------|---------|-------------|
| `--project-dir` | `-p` | `Path` | `.` (cwd) | Root directory of the documentation project |
| `--permissive` | | `bool` flag | `False` | Continue on missing nav files or assets instead of exiting with error |
| `--help` | | | | Show help and exit |

---

## Subcommands

### `inspect-nav`

Print the resolved navigation order without producing any output files.

```
zensical-pdf inspect-nav [OPTIONS]
```

**Options**: global options only.

**Exit codes**:
- `0` — nav resolved successfully (warnings may have been emitted)
- `1` — fatal error (missing files in non-permissive mode, config unreadable)

**Stdout** (structured, for piping):
```
Project directory : /path/to/project
Config file       : mkdocs.yml
Docs directory    : /path/to/project/docs
Pages (5 total)   :
  1. docs/index.md
  2. docs/guide/overview.md
  3. docs/guide/setup.md
  4. docs/reference/api.md
  5. docs/about.md
```

**Stderr**: warnings (e.g., no nav section found, falling back to sorted scan).

---

### `aggregate`

Aggregate documentation pages into a single combined Markdown file and copy local assets.

```
zensical-pdf aggregate [OPTIONS]
```

**Options**: global options only.

**Exit codes**:
- `0` — aggregation succeeded
- `1` — fatal error (unreadable file, missing asset with `error` policy)

**Output files** (written by this command):
- `<build_dir>/combined.md` — aggregated Markdown
- `<build_dir>/assets/` — copied local image assets
- `<build_dir>/manifest.json` — aggregation manifest

**Stderr**: warnings for missing assets (when policy is `warn`), skipped front matter, unsupported constructs.

---

### `build`

Run the complete pipeline: nav → aggregate → Pandoc → Typst → PDF.

```
zensical-pdf build [OPTIONS]
```

**Additional options**:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `--output` | `Path` | from config or `dist/documentation.pdf` | Override the PDF output path |

**Exit codes**:
- `0` — PDF generated successfully
- `1` — any pipeline step failed

**Output files** (written by this command):
- All files from `aggregate`
- `<build_dir>/document.typ` — Typst source generated by Pandoc
- `<output>` — final PDF
- `dist/manifest.json` — full build manifest

---

### `doctor`

Validate the local environment without producing any output files.

```
zensical-pdf doctor [OPTIONS]
```

**Options**: global options only.

**Exit codes**:
- `0` — all checks pass or warn
- `1` — one or more checks fail

**Stdout**: Rich-formatted panel listing each check with status (✓ pass / ⚠ warn / ✗ fail) and detail message.

**Example output**:
```
┌─ Environment Check ──────────────────────────────────────────────────────┐
│  ✓ Python          3.11.9                                                │
│  ✓ Pandoc          3.2.1 (≥ 3.1.2 required)                             │
│  ✓ Typst           0.11.0                                                │
│  ✓ Config detected mkdocs.yml                                            │
│  ✓ Docs directory  docs/ (exists, readable)                              │
│  ✓ Output dir      dist/ (writable)                                      │
└──────────────────────────────────────────────────────────────────────────┘
All checks passed.
```

## Error message format

All fatal errors follow this pattern on stderr:

```
ERROR: <short description>
  <detail or hint>
  <suggested fix>
```

Example:
```
ERROR: Pandoc is not available on PATH.
  The build command requires Pandoc ≥ 3.1.2 to convert Markdown to Typst.
  Install Pandoc: https://pandoc.org/installing.html
```
